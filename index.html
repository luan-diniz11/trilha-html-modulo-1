História dos computadores

Os computadores começaram sua jornada no século XX e revolucionaram a forma como processamos informações. A evolução tecnológica foi extraordinária e transformou completamente nossa sociedade.

O primeiro computador eletrônico foi o ENIAC, criado em 1946, que ocupava uma sala inteira. Atualmente, temos dispositivos muito mais potentes que cabem na palma da mão.

"A tecnologia é melhor quando traz as pessoas juntas." - Matt Mullenweg

Nota: Os computadores evoluíram de máquinas gigantescas para dispositivos portáteis e eficientes.

Fato importante: A evolução dos computadores incluiu passagens por diferentes gerações, desde máquinas de tubo de vácuo até os modernos processadores de silício.

Para mais informações, visite Wikipedia.

O que são Clients?

Client é a máquina ou programa que solicita serviços de um servidor. Em português, podemos chamar de "cliente".

Os clientes podem ser:

  • Navegadores web (browsers)
  • Aplicativos de desktop
  • Aplicativos móveis
  • Qualquer programa que se conecte a um servidor

A principal característica de um client é que ele inicia a comunicação com o servidor. A relação é de dependência: o client depende do server para obter os dados.

Você está usando um client agora! Este navegador é um client que está baixando e exibindo este arquivo.

O que são Servers?

Um servidor é um computador ou software que fornece serviços e recursos para clientes. O servidor fica sempre ligado aguardando requisições.

Características principais de um servidor:

  1. Disponibilidade 24/7
  2. Alta capacidade de processamento
  3. Armazenamento grande de dados
  4. Capacidade de atender múltiplos clientes

Exemplos de servidores:

  • Servidor Web (Apache, Nginx)
  • Servidor de Banco de Dados (MySQL, PostgreSQL)
  • Servidor de Email
  • Servidor de Aplicação

A relação client-server é fundamental na arquitetura da web moderna. Sem servidores, não teríamos onde armazenar nossas informações.

Dica: Todos os sites que você visita estão hospedados em servidores espalhados pelo mundo.

Como é uma estrutura básica de um HTML?

A estrutura básica de um documento HTML é simples e segue um padrão definido pelo W3C.

Elementos essenciais:

  1. <!DOCTYPE html> - Declara o tipo de documento
  2. <html> - Elemento raiz
  3. <head> - Informações sobre o documento
  4. <body> - Conteúdo visível da página
"HTML é a linguagem da web. Sem ele, não poderíamos criar páginas web."

As tags HTML são estruturadas em pares: uma tag de abertura <tag> e uma de fechamento </tag>. Algumas tags são auto-fecháveis como <hr /> e <img />.

Bom saber: Uma estrutura bem organizada facilita a manutenção e o entendimento do código.

Entendendo a diferença entre listas ordenadas e não ordenadas

As listas são estruturas fundamentais em HTML para organizar informações de forma clara e hierárquica.

Listas Não Ordenadas (Unordered Lists - UL)

Usadas quando a ordem não importa. São marcadas com bullets (pontos ou círculos).

  • Primeiro item
  • Segundo item
  • Terceiro item

Listas Ordenadas (Ordered Lists - OL)

Usadas quando a ordem é importante. São marcadas com números ou letras.

  1. Primeiro passo
  2. Segundo passo
  3. Terceiro passo

Comparação visual:

Lista Não Ordenada Lista Ordenada
• Item A
• Item B
• Item C		 1. Item A
2. Item B
3. Item C

Lembre-se: Toda lista é composta por itens de lista (<li>) agrupados em uma lista ordenada (<ol>) ou não ordenada (<ul>).

Resumo de Tags Utilizadas

Tags aprendidas neste módulo:

  • <h1> até <h6> - Títulos e subtítulos
  • <p> - Parágrafos
  • <mark> - Texto marcado em destaque
  • <small> - Texto pequeno
  • <i> - Texto itálico
  • <u> - Texto sublinhado
  • <strong> - Texto em negrito (forte ênfase)
  • <ol> - Lista ordenada
  • <ul> - Lista não ordenada
  • <li> - Item de lista
  • <a> - Link (âncora)
  • <hr> - Linha horizontal
  • <sub> - Texto subscrito (como em H2O)
  • <sup> - Texto sobrescrito (como em x2)
  • <blockquote> - Citação em bloco
  • <font> - Alteração de cor e fonte (deprecated)
  • <del> - Texto deletado
  • <abbr> - Abreviação com explicação
